# 🍼 LactaRede


## 📱 Sobre o projeto

O LactaRede é um aplicativo Android desenvolvido em Kotlin com Jetpack Compose, criado para facilitar o processo de doação de leite materno e aproximar doadoras dos pontos de coleta. O aplicativo permite que a usuária navegue pelas principais funcionalidades da solução, como consultar pontos de coleta, realizar uma simulação de doação, visualizar agendamentos e acessar informações sobre o processo de doação.

# 🎯 Objetivo do aplicativo

O objetivo do LactaRede é oferecer uma solução digital para auxiliar mulheres interessadas em realizar a doação de leite materno. A aplicação busca tornar o processo mais simples e acessível, permitindo que a usuária:

- Consulte pontos de coleta;
- Visualize informações sobre a doação;
- Realize uma simulação de agendamento;
- Consulte seus agendamentos;
- Navegue pelas principais funcionalidades do aplicativo;
- Receba informações importantes sobre o processo de doação.
